

# 芋道开发平台

## 介绍

- 芋道源码目录：https://gitee.com/yudaocode、https://gitee.com/zhijiantianya

后端项目关系：ruoyi-vue》（全面升级）》ruoyi-vue-pro》（微服务化）》yudao-cloud

- 面向Java开发的学习专栏：https://gitee.com/yudaocode/SpringBoot-Labs

包括Spring Boot、Spring Cloud、Spring Cloud Alibaba、Dubbo、分布式消息队列、分布式事务等内容。

- 开发指南视频教程：https://www.bilibili.com/video/BV1sWDWYGEMc
- 系统内置多种业务功能。

1、业务系统（按需）：

商城系统（电子商城、Mall）：包括商品中心目录，商品列表、商品分类、商品品牌、商品属性、商品评论；订单中心（交易中心）目录，交易配置、订单列表、售后退款、快递发货、门店自提、分销管理；营销中心目录，内容管理、优惠券、秒杀活动、拼团活动、砍价活动、商城装修、优惠活动；统计中心目录，会员统计、商品统计、交易统计。

企业资源计划系统（ERP系统）：产品管理目录，产品信息、产品分类、产品单位；库存管理目录，仓库信息、产品库存、出入库明细、其它入库、其它出库、库存调拨、库存盘点；包括采购管理目录，采购订单、采购入库、采购退货、供应商信息；销售管理目录，销售订单、销售出货、销售退货、客户信息；财务管理目录，付款单、收款单、结算客户。

客户关系管理（CRM系统）：待办事项、线索管理、客户管理、联系人管理、客户公海、商机管理、合同管理、回款管理、回款计划、产品管理。

内容管理系统（CMS）。

论坛社区系统（BBS）。

办公自动化（OA）。

微信公众号：账号管理、数据统计、标签管理、粉丝管理、消息管理、菜单管理、自动回复、素材管理、图文草稿箱、图文发表记录、消息模版。

AI大模型：AI对话、AI绘画、AI写作、AI音乐、AI知识库、AI思维导图、控制台（API密钥、模型配置、聊天角色、聊天管理、绘画管理、音乐管理、写作管理、导图管理）。

2、通用模块（内置功能）：

①必选（对应精简版）。

系统功能（System）：登录、首页、用户管理、令牌管理、应用管理、租户管理、租户套餐、部门管理、岗位管理、菜单管理、角色管理、操作日志、登录日志、短信渠道、短息模板、短信日志、字典管理、字典数据、敏感词管理、错误码管理、通知公告等。

基础设施（Infra）：代码生成、系统接口、数据库文档、文件配置、文件列表、配置管理、定时任务、调度日志、访问日志、错误日志、MySQL监控、Redis监控、Java监控、链路追踪、日志中心等。

②可选。

工作流程（BPM）：流程模型、流程表单、流程分类、用户分组、流程监听器、流程表达式、流程实例、流程任务、发起流程、我的流程、待办任务、已办任务、抄送我的。

支付系统（Pay）：应用信息、支付订单、退款订单、转账订单、回调通知、接入示例。

数据报表（Visualization）：报表设计器、大屏设计器。

会员中心（Member）：会员配置、会员管理、会员标签、会员等级、会员分组、会员积分、会员签到。

### 前端

- yudao-ui-admin-vue2：https://gitee.com/yudaocode/yudao-ui-admin-vue2、（演示地址）[http://dashboard.yudao.iocoder.cn](http://dashboard.yudao.iocoder.cn/)

芋道管理后台，采用Vue Element Admin实现。基于Vue2+Element UI实现，支持RBAC动态权限、数据权限、SaaS多租户、Flowable工作流、三方登录、支付、短信、商城、CRM、ERP、AI大模型等功能。

- yudao-ui-admin-vue3：https://gitee.com/yudaocode/yudao-ui-admin-vue3、（演示地址）[http://dashboard-vue3.yudao.iocoder.cn](http://dashboard-vue3.yudao.iocoder.cn/)、（本地运行）http://10.6.20.16/index

芋道管理后台，基于Vue3+Element Plus实现，使用Vue3、Vite4、typescript等技术开发，支持RBAC动态权限、数据权限、SaaS多租户、Flowable工作流、三方登录、支付、短信、商城、CRM、ERP、AI大模型等功能。采用vue-element-plus-admin实现（https://gitee.com/kailong110120130/vue-element-plus-admin），使用Element Plus免费开源的中后台模版。

- yudao-ui-admin-vben：https://gitee.com/yudaocode/yudao-ui-admin-vben、（演示地址）[http://dashboard-vben.yudao.iocoder.cn](http://dashboard-vben.yudao.iocoder.cn/)、（本地运行）http://10.6.20.16:5777/analytics

ruoyi-vue-pro-vben芋道管理后台，基于vben5.0最新版本，使用最新的vue3、vite7、ant-design-vue、typescript语法进行重构开发，支持springboot3、springcloud版本。采用最新vue-vben-admin v5实现（Vben Admin文档：https://doc.vben.pro/guide/introduction/vben.html），支持多种免费开源的中后台模版，包括Ant Design Vue、Element Plus、Naive UI、TDesign。

- yudao-ui-admin-uniapp：https://gitee.com/yudaocode/yudao-ui-admin-uniapp

芋道管理后台的移动端，采用Vue3+TypeScript+Vite5+UnoCSS+wot-design-uni+z-paging构成，使用最新的前端技术栈，无需依赖HBuilderX，通过命令行方式运行H5、小程序和App。基于uni-app+uniui实现，支持H5、APP、微信小程序、支付宝小程序等，内置了约定式路由、layout布局、请求封装、请求拦截、登录拦截、UnoCSS、i18n多语言等基础功能，提供了代码提示、自动格式化、统一配置、代码片段等辅助功能。

- yudao-mall-uniapp：https://gitee.com/yudaocode/yudao-mall-uniapp

芋道商城，基于Vue3+Uniapp实现，支持分销、拼团、砍价、秒杀、优惠券、积分、会员等级、小程序直播、页面DIY等功能。

- yudao-ui-go-view：https://gitee.com/yudaocode/yudao-ui-go-view

GoView是一个Vue3搭建的低代码数据可视化开发平台，将图表或页面元素封装为基础组件，无需编写代码即可完成业务需求。它的技术栈为Vue3+TypeScript4+Vite2+NaiveUI+ECharts5+Axios+Pinia2+PlopJS。

### 后端

- ruoyi-vue-pro：（完整版）https://gitee.com/zhijiantianya/ruoyi-vue-pro、（精简版）https://gitee.com/yudaocode/yudao-boot-mini、（ruoyi-vue-pro开发指南、文档）https://doc.iocoder.cn、（MOM的Git地址，JAVA版）http://10.9.44.9:7001/KEDA/mom-api

RuoYi-Vue全新Pro版本，优化重构所有功能。基于Spring Boot多模块架构。是Spring Boot单体架构。基于Spring Boot+MyBatis Plus+Vue&Element实现的后台管理系统+微信小程序，支持RBAC动态权限、数据权限、SaaS多租户、Flowable工作流、三方登录、支付、短信、商城、CRM、ERP、IoT、AI等。后端采用Spring Boot多模块架构、MySQL+MyBatis Plus、Redis+Redisson。

- yudao-cloud：（完整版）https://gitee.com/zhijiantianya/yudao-cloud、（精简版）https://gitee.com/yudaocode/yudao-cloud-mini、（文档）https://cloud.iocoder.cn

ruoyi-vue-pro全新Cloud版本，优化重构所有功能。基于Spring Cloud微服务架构。基于Spring Cloud Alibaba+Gateway+Nacos+RocketMQ+Vue&Element实现的后台管理系统+用户小程序，支持RBAC动态权限、多租户、数据权限、工作流、三方登录、支付、短信、商城、CRM、ERP、AI等功能。后端采用Spring Cloud Alibaba微服务架构、Nacos（注册中心+配置中心）、定时任务XXL-Job、服务保障Sentinel、服务网关Gateway、分布式事务Seata。
